The project to open first

Indian Creator Lab

Python · pandas · scikit-learn · YouTube Data API · SQLite · Streamlit

Recruiters keep asking for “a dashboard and a story.” This is that. Upload a title and a cut (or a file). The app compares it to an Indian watchlist and returns a view range, engagement, typical-vs-outlier, and the closest real videos. Totals are stored as snapshots, so trending is a curve. Engagement is (likes + comments) / views. Outlier is this video vs that creator’s median — so a 10k channel and Technical Guruji are not ranked the same way.
