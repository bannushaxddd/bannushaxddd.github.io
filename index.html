Selected work · sample metrics

01

Project lead time

Power BI · one row per activity

An industrial queue was living in lists. I modeled each activity with family, category, priority, owner, and dates, then put average next to P90 so one long job cannot hide inside the mean.

Useful because a review can see which category is late, and which owner is carrying the wait, without opening the source list.

02

Scrap value

SharePoint workbook · one posting line

Finance had a raw dump and a summary file. I bound the model to the dump only, set the grain at one posting, and dropped any chart the file could not support.

Useful because a card can be traced to a line: reason, material, item, and day. A summary workbook cannot hide a posting.

03

5S audits

Power Apps · SharePoint · scorecards

Paper checklists became one row per audit, across five pillars, with photos and actions. Write-back is limited to the zones an identity may touch. Drafts stay out of the trend.

Useful because a lead sees the weakest pillar against a qualifying bar, instead of a folder of scanned sheets.
